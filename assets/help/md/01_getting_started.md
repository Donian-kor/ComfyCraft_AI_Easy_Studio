# 시작하기

ComfyCraft AI Easy Studio에 오신 것을 환영합니다! 이 프로그램은 **LM Studio**의 똑똑한 프롬프트 작성 능력과 **ComfyUI**의 강력한 이미지 생성 기술을 하나로 합친 통합 이미지 생성 프로그램입니다. 파이썬이나 복잡한 노드 연결을 몰라도 누구나 쉽게 고품질 이미지를 생성할 수 있습니다.

## 주요 특징

- **AI 프롬프트 마법사**: 한국어 아이디어를 입력하면 AI가 상세한 영문 프롬프트로 자동 확장
- **자동 최적 설정**: 모델만 선택하면 Steps, CFG, Sampler 등 최적값 자동 적용
- **강력한 얼굴 보정**: FaceDetailer로 얼굴 영역만 자동 인식해 픽셀 단위 보정
- **히스토리 관리**: 최근 생성 이미지 4장 썸네일로 저장, 클릭 한 번으로 설정 복원
- **클립보드 연동**: 프롬프트/이미지 원클릭 복사

## 빠른 시작

### 1. 필수 프로그램 설치

| 프로그램 | 용도 | 다운로드 |
|----------|------|----------|
| **LM Studio** | 프롬프트 확장용 언어 모델 서버 | [lmstudio.ai](https://lmstudio.ai/) |
| **ComfyUI** | 이미지 생성 백엔드 | [github.com/comfyanonymous/ComfyUI](https://github.com/comfyanonymous/ComfyUI) |

### 2. 서버 실행

**LM Studio**
1. 언어 모델 다운로드 (예: qwen2.5-7b-instruct 등)
2. 좌측 `↔` 아이콘 클릭 → Local Server 탭
3. 포트 `1234` 확인 후 `Start Server` 클릭

**ComfyUI**
1. 터미널에서 `python main.py --listen --port 8188` 실행
2. 브라우저에서 `http://localhost:8188` 접속 확인

### 3. 프로그램 실행

```bash
# 가상환경 활성화
python -m venv .venv
.venv\Scripts\Activate.ps1

# 의존성 설치
pip install -r requirements.txt

# 실행
python main.py
```

### 4. 첫 이미지 생성

1. 상단 `LM Studio 연결 확인`, `ComfyUI 연결 확인` 버튼 클릭 → 초록불 확인
2. 사용할 모델 선택 (프롬프트용 LM / 생성용 ComfyUI)
3. 한국어로 아이디어 입력 (예: "비 오는 날 창가에 앉은 고양이")
4. `✨ AI 프롬프트 마법사로 영문 확장 생성` 클릭
5. 초록색 `생성 시작` 버튼 클릭!
