# 기본 워크플로우

전체 이미지 생성 과정은 **3단계**로 이루어집니다. 각 단계는 순차적으로 진행되며, 이전 단계의 결과가 다음 단계에 영향을 줍니다.

---

## 1단계: 아이디어 입력 & AI 프롬프트 변환

**목표**: 한국어 아이디어를 모델이 이해하기 좋은 영문 프롬프트로 변환

| 순서 | 동작 | 설명 |
|------|------|------|
| 1 | **언어 모델 선택** | 드롭다운에서 LM Studio 모델 선택 (큰 모델일수록 상세한 프롬프트 생성) |
| 2 | **아이디어 입력** | 한국어로 원하는 이미지 묘사 (구체적일수록 좋음) |
| 3 | **AI 프롬프트 마법사 실행** | `✨ AI 프롬프트 마법사` 버튼 클릭 → 영문 프롬프트 자동 생성 |
| 4 | **프롬프트 확인/수정** | 생성된 영문 프롬프트 하단 에디터에서 직접 수정 가능 |

> **입력 팁**: "무엇을 그릴지(주제) + 어떤 스타일로(화풍) + 분위기/조명/구도/품질 키워드" 조합이 가장 효과적입니다.
> 
> **자세한 작성법**: [프롬프트 작성 가이드](04_prompt_writing.html) 참조

---

## 2단계: 생성 옵션 설정

**목표**: 모델 선택 및 생성 파라미터 조정

| 설정 항목 | 설명 | 자동/수동 |
|-----------|------|-----------|
| **생성 모델** | ComfyUI 모델 드롭다운에서 선택 → **최적 설정 자동 적용** (Steps, CFG, Sampler, VAE, CLIP) | 자동 |
| **이미지 비율** | 프리셋 버튼(정사각/세로/와이드) 또는 직접 입력 (64의 배수 권장) | 수동 |
| **고급 설정** | 시드, Steps, CFG, Sampler, Scheduler, Denoise (체크박스로 열기) | 자동+수동 |
| **FaceDetailer** | 얼굴 보정 ON/OFF (기본값 권장, 세부 조정은 별도 가이드) | 수동 |

> **모델별 자동 설정**: 모델 선택 시 하단 배지로 `✓ FLUX_GGUF 최적 설정 적용됨 (CFG 1.0 / 20스텝)` 형태로 표시됩니다.
> 
> **상세 파라미터**: [생성 옵션 상세](05_generation_options.html) 참조
> 
> **얼굴 보정**: [FaceDetailer 얼굴 보정](06_facedetailer.html) 참조

## 3단계: 생성 실행 & 결과 활용

**목표**: 이미지 생성 및 후속 작업

| 단계 | 동작 | 설명 |
|------|------|------|
| 1 | **생성 시작** | 초록색 `▶ 생성 시작` 버튼 클릭 |
| 2 | **진행 확인** | 진행바, 경과시간, 퍼센트 실시간 표시 (`■ 중지`로 중단 가능) |
| 3 | **결과 확인** | 우측 패널에 이미지 + 하단 정보(모델, 해상도, 시드, 소요시간, Steps, CFG) |
| 4 | **후속 액션** | 아래 버튼으로 활용 |

### 후속 액션 버튼

| 버튼 | 기능 |
|------|------|
| 📋 **프롬프트 복사** | 영문 프롬프트 클립보드 복사 |
| 📋 **이미지 복사** | 생성된 이미지 클립보드 복사 (다른 앱에 Ctrl+V로 붙여넣기) |
| 💾 **이미지 저장** | 파일로 저장 (자동 명명: `모델_시드_날짜.png`) |
| 📁 **출력 폴더 열기** | 저장 폴더 탐색기에서 열기 |

### 히스토리 (우측 썸네일 패널)
- 최근 4개 생성 결과 **자동 저장** (프로그램 종료 시 초기화)
- 썸네일 **클릭 시 당시 설정 완전 복원** (프롬프트, 시드, 모델, FaceDetailer 설정 등)
- 썸네일 우측 `×`로 개별 삭제 가능

> **히스토리 활용법**: [히스토리 & 단축키](07_history_shortcuts.html) 참조

## 초보자를 위한 3가지 핵심 팁

1. **같은 구도 재생성**: 🔒 **시드 고정** 토글 ON → 프롬프트만 살짝 수정 → 생성
2. **빠른 테스트**: Steps 15~20, 해상도 512×512로 테스트 → 본 생성 시 올리기
3. **모델별 강점**: FLUX=자연스러운 실사/텍스트, ZImage=고속/애니, SDXL=범용 고품질, Z-ANIME=웹툰/애니
