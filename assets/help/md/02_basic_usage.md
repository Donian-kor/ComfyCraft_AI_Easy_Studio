# 기본 사용법

전체 워크플로우는 **3단계**로 구성되어 있습니다. 순서대로 따라하면 누구나 쉽게 고품질 이미지를 생성할 수 있습니다.

## 1단계: 한국어 아이디어 입력 & AI 프롬프트 변환

### 언어 모델 선택
- 드롭다운에서 사용할 LM Studio 모델 선택
- 모델이 안 보이면 LM Studio에서 모델 로드 후 서버 재시작

### 아이디어 입력
```
입력 예시:
"비 오는 날 네온사인 빛나는 도시 창가에 앉은 은발 안드로이드 소녀, 
영화 같은 조명, 사이버펑크 분위기, 8k 해상도"
```

**팁**: 구체적으로 적을수록 결과가 좋습니다. 분위기, 조명, 구도, 스타일 키워드를 넣어보세요.

### AI 프롬프트 마법사 실행
- `✨ AI 프롬프트 마법사로 영문 확장 생성` 버튼 클릭
- LM Studio가 한국어를 분석해 최적화된 영문 프롬프트 생성
- 생성된 프롬프트는 하단 에디터에서 **직접 수정 가능**

### 부정 프롬프트 (선택)
- SDXL 계열 모델용 품질 저하 방지 키워드
- FLUX, ZImage 계열은 자동 숨김 처리됨
- 기본값으로 충분한 경우가 많음

---

## 2단계: 핵심 생성 옵션

### 생성 모델 선택 (AI 엔진)
- ComfyUI에 로드된 모델 목록에서 선택
- 모델 변경 시 **최적 설정 자동 적용** (Steps, CFG, Sampler, Scheduler)
- 모델별 권장 설정 배지 표시됨

### 이미지 비율 선택
| 비율 | 해상도 | 용도 |
|------|--------|------|
| □ 정사각 (1:1) | 1024×1024 | 프로필, 썸네일 |
| ▯ 세로형 (9:16) ★ | 896×1152 | 모바일 배경, 세로 일러스트 |
| ▭ 와이드 (16:9) | 1152×896 | 모니터 배경, 풍경 |

- 프리셋 버튼 원클릭 적용
- 직접 숫자 입력도 가능 (64의 배수 권장)

### 고급 설정 (체크박스로 열기)
- **시드**: -1 = 랜덤, 고정 시 같은 구도 재현 가능
- **Steps**: 계산 횟수 (기본 20~30, 높을수록 정교하지만 느림)
- **CFG**: 프롬프트 충실도 (기본 3.5~7, 높을수록 프롬프트 엄격 준수)
- **Sampler / Scheduler**: 모델 프로파일 따라 자동 설정
- **Denoise**: img2img 시 원본 유지 비율 (기본 1.0)

### FaceDetailer (얼굴 보정)
- 체크박스 ON → 얼굴 자동 감지 후 픽셀 단위 보정
- 기본값으로 충분함 (세부 조정은 [얼굴 보정 가이드](06_facedetailer.html) 참조)

## 3단계: 생성 실행 및 결과 확인

### 생성 시작
- 초록색 `▶ 생성 시작` 버튼 클릭
- 진행바, 경과시간, 퍼센트 실시간 표시
- 중간에 `■ 중지` 버튼으로 중단 가능

### 결과 확인
- 생성 완료 시 우측 패널에 이미지 표시
- 하단 정보: 모델, 해상도, 시드, 소요시간, Steps, CFG

### 후속 액션
| 버튼 | 기능 |
|------|------|
| 📋 프롬프트 복사 | 영문 프롬프트 클립보드 복사 |
| 📋 이미지 복사 | 생성된 이미지 클립보드 복사 (다른 앱에 붙여넣기 가능) |
| 💾 이미지 저장 | 파일로 저장 (자동 명명: 모델_시드_날짜.png) |
| 📁 출력 폴더 열기 | 저장 폴더 탐색기에서 열기 |

### 히스토리 (우측 썸네일)
- 최근 4개 생성 결과 자동 저장
- 썸네일 클릭 시 **당시 설정 완전 복원** (프롬프트, 시드, 모델, FaceDetailer 설정 등)
- 썸네일 우측 `×`로 개별 삭제 가능

## 워크플로우 요약

```
[아이디어 입력] → [AI 프롬프트 확장] → [모델/옵션 선택] → [생성] → [결과 활용]
     │                │                   │              │          │
  한국어           영문 최적화          자동/수동       진행바      복사/저장/
  자연어           프롬프트             설정            실시간      히스토리
```

---

## 자주 쓰는 팁

1. **같은 구도 재생성**: 시드 고정(🔒) 후 프롬프트만 살짝 수정
2. **빠른 테스트**: Steps 낮추고(15~20), 해상도 작게(512×512) 테스트 후 본 생성
3. **프롬프트 재사용**: 히스토리 썸네일 클릭 → 프롬프트 복사 → 새 아이디어에 적용
4. **모델별 특성**: FLUX=자연스러움, ZImage=애니/웹툰, SDXL=실사/일반
