# 히스토리 & 단축키

최근 생성한 이미지 4개를 **우측 썸네일 패널**에 자동 저장하고, 클릭 한 번으로 당시 설정을 완전히 복원할 수 있습니다. 작업 효율을 높여주는 키보드 단축키와 숨겨진 기능들도 함께 설명합니다.

---

## 히스토리/썸네일

### 히스토리 패널 구조

```
┌─────────────────────────────────────┐
│  📜 생성 히스토리 (최근 4개)          │
├─────────────────────────────────────┤
│  [썸네일 1]  [썸네일 2]              │
│  [썸네일 3]  [썸네일 4]              │
│                                     │
│  각 썸네일 우측: × 삭제 버튼         │
└─────────────────────────────────────┘
```

### 자동 저장되는 정보

썸네일 클릭 시 **다음 모든 설정 복원**:

| 복원 항목 | 설명 |
|-----------|------|
| **이미지** | 생성된 결과 이미지 표시 |
| **한국어 프롬프트** | 1단계 입력한 원본 아이디어 |
| **영문 프롬프트** | AI 마법사로 생성/수정한 프롬프트 |
| **부정 프롬프트** | 입력된 부정 프롬프트 (SDXL용) |
| **ComfyUI 모델** | 사용한 생성 모델 |
| **해상도** | Width × Height |
| **시드** | 사용된 시드값 (고정 시 재현 가능) |
| **Steps / CFG** | 생성 파라미터 |
| **Sampler / Scheduler** | 샘플러 설정 |
| **Denoise** | 디노이즈 강도 |
| **FaceDetailer 설정** | 켜짐/꺼짐 + 17개 세부 옵션 전체 |
| **Z-ANIME 스타일** | 웹툰/일본애니/기본 선택 상태 |

---

### 사용법

#### 썸네일 클릭 → 설정 복원
1. 우측 패널에서 원하는 썸네일 **클릭**
2. 메인 화면의 모든 입력창/설정이 **자동으로 당시 값으로 변경**
3. 즉시 `생성 시작` 눌러 **같은 조건으로 재생성** 가능

#### 썸네일 삭제
- 썸네일 우측 상단 `×` 버튼 클릭
- 개별 삭제 가능, 빈 슬롯은 다음 생성 시 채워짐

#### 히스토리 초기화
- 프로그램 재시작 시 히스토리 초기화됨
- 영구 저장은 `이미지 저장` 버튼으로 파일로 보관

---

### 활용 시나리오

#### 1. 마음에 드는 결과 조금 수정해서 다시 뽑기
```
썸네일 클릭 → 프롬프트 살짝 수정 → 생성 시작
→ 구도/캐릭터 유지하며 디테일만 변경
```

#### 2. 시드 고정으로 캐릭터 고정하며 포즈 변경
```
썸네일 클릭 → 🔒 시드 고정 토글 ON → 프롬프트에서 포즈 키워드만 변경 → 생성
→ 같은 캐릭터, 다른 포즈/표정 생성
```

#### 3. FaceDetailer 설정 비교
```
썸네일 클릭 (FaceDetailer OFF) → 생성 → 결과 확인
썸네일 클릭 (FaceDetailer ON)  → 생성 → 결과 비교
→ 보정 전후 바로 비교 가능
```

#### 4. 다른 모델로 같은 프롬프트 테스트
```
썸네일 클릭 → ComfyUI 모델만 변경 → 생성 시작
→ 같은 프롬프트로 모델별 스타일 비교
```

#### 5. 프롬프트 재사용
```
썸네일 클릭 → 📋 프롬프트 복사 → 새 탭/메모장에 붙여넣기
→ 나중에 다른 프로젝트에서 활용
```

### 제한사항

| 항목 | 제한 |
|------|------|
| **저장 개수** | 최대 4개 (FIFO, 5번째부터 가장 오래된 것 삭제) |
| **지속성** | 프로그램 종료 시 초기화 (메모리 상주) |
| **용량** | 썸네일 이미지 메모리 보관 (원본 파일은 출력 폴더에 별도 저장) |
| **동기화** | 다중 인스턴스 실행 시 각자 독립적 히스토리 |

---

### 출력 폴더와의 관계

| 구분 | 히스토리 썸네일 | 출력 폴더 저장 파일 |
|------|-----------------|---------------------|
| **저장 위치** | 메모리 (RAM) | 디스크 (`output/` 폴더) |
| **파일명** | 자동 생성 | `{모델}_{시드}_{날짜시간}.png` |
| **보존 기간** | 프로그램 실행 중만 | 영구 보관 (수동 삭제 전까지) |
| **용도** | 빠른 복원/비교 | 최종 결과물 아카이브 |

**팁**: 중요 결과는 반드시 `💾 이미지 저장` 또는 `📁 출력 폴더 열기`로 파일 보관하세요.

## 마우스 팁

### 헤더 버튼
| 버튼 | 우클릭/길게 누르기 | 설명 |
|------|-------------------|------|
| 🎨 ComfyUI 상태 | 우클릭 | 설정 대화상자 바로 열기 |
| 💬 LM Studio 상태 | 우클릭 | 설정 대화상자 바로 열기 |
| ⚙️ 설정 | - | 설정 대화상자 열기 |
| ❓ 도움말 | - | 도움말 창 열기 |

### 사이드바
- **마우스 호버**: 사이드바 자동 확장 (아이콘 → 아이콘+텍스트)
- **마우스 떠남**: 자동 축소 (아이콘만)
- **카드 클릭**: 홈 화면에서 해당 탭으로 바로 이동

### 썸네일 (우측 패널)
- **클릭**: 설정 완전 복원
- **우클릭**: 컨텍스트 메뉴 (복사, 저장, 삭제 - 구현 예정)
- **Drag & Drop**: 다른 폴더로 이미지 파일 드래그 가능 (구현 예정)

### 슬라이더
- **휠 스크롤**: 값 미세 조정 (±1)
- **Shift+휠**: 큰 단위 조정 (±10)
- **우클릭**: 기본값으로 리셋 (구현 예정)

## 숨겨진 기능 & 팁

### 1. 설정 자동 저장
- 모델 변경, 슬라이더 조작 등 주요 설정은 **자동으로 `app_config.json`에 저장**
- 프로그램 재시작 시 마지막 상태 복원
- `⚙️ 설정` → `💾 설정 저장 후 닫기`로 강제 저장도 가능

### 2. 모델별 자동 프로파일
```
모델 선택 → 자동으로 적용되는 것들:
✓ Steps, CFG 기본값
✓ Sampler, Scheduler 추천값  
✓ VAE, CLIP 경로 (모델에 포함된 경우)
✓ 네거티브 프롬프트 표시/숨김
✓ Z-ANIME 스타일 영역 표시/숨김
✓ 권장 해상도 프리셋
```

### 3. 프롬프트 카운터
- 각 프롬프트 입력창 하단에 **실시간 문자 수 표시**
- 토큰 수 대략 추정: 영문 기준 문자 수 ÷ 4 ≈ 토큰 수
- CLIP 제한(77 토큰 ≈ 300자) 고려해 길이 조절

### 4. 시드 고정 워크플로우
```
1. 마음에 드는 결과 생성 → 히스토리에 저장됨
2. 히스토리 썸네일 클릭 → 당시 시드값 자동 입력됨
3. 🔒 시드 고정 버튼 토글 ON
4. 프롬프트만 수정하며 같은 구도/캐릭터로 변형 생성
5. 완료 후 🔒 토글 OFF (다음엔 새 랜덤 시드)
```

### 5. 테마별 최적화
| 테마 | 추천 상황 |
|------|-----------|
| **Fluent Dark** | 기본, 장시간 작업, 눈 피로 최소화 |
| **Fluent Light** | 밝은 환경, 프린트/스크린샷 공유 시 |
| **Midnight Navy** | 야간 작업, 집중 모드 |
| **Purple Nebula** | 창작 분위기, 색감 영감 |
| **Emerald Forest** | 편안한 분위기, 장시간 편집 |

### 6. 로그 창 활용
- **에러 발생 시**: 로그 창 `📋 복사` → 이슈 리포트에 첨부
- **모델 로딩 확인**: `모델 프로파일 로드: [FAMILY] name` 로그로 프로파일 적용 확인
- **연결 디버깅**: 연결 시도/성공/실패 상세 로그 기록

### 7. 출력 파일명 규칙
```
{모델명}_{시드}_{YYYYMMDD_HHMMSS}.png
예: flux1-dev-Q4_K_S_1234567890_20260115_143022.png

→ 모델/시드/시간으로 정렬/검색 용이
```

### 8. 외부 프롬프트 파일
`workflows/prompt.json` 수정으로 프롬프트 템플릿 커스터마이징:
```json
{
  "system_prompt": "당신의 커스텀 시스템 프롬프트",
  "negative_default": "당신의 기본 부정 프롬프트"
}
```

## 워크플로우별 추천 설정

### 빠른 테스트 (30초 내 결과)
```
모델: ZImage Turbo / FLUX Schnell
Steps: 8~12 (Turbo) / 4~8 (Schnell)
해상도: 512×512
FaceDetailer: OFF
고급설정: 모두 기본
```

### 고품질 최종본 (2~5분)
```
모델: FLUX Dev / ZImage Base / SDXL
Steps: 30~50
해상도: 1024×1024 이상
FaceDetailer: ON (기본값)
Sampler: DPM++ 2M Karras / UniPC
Scheduler: karras
```

### 캐릭터 일관성 유지 (시드 고정)
```
1. 기본 생성 → 결과 확인
2. 히스토리 클릭 → 시드 자동 입력
3. 🔒 시드 고정 ON
4. 프롬프트에서 포즈/표정/배경만 변경
5. 반복 생성
```

### 웹툰/만화 컷 연작
```
모델: Z-ANIME (z_anime_base 등)
스타일: 웹툰 (고정)
해상도: 896×1152 (세로 컷 최적)
시드: 고정하여 캐릭터 일관성
프롬프트: 컷별 상황만 변경 (캐릭터 설명 유지)
```

## 트러블슈팅 단축법

| 상황 | 즉시 시도할 것 |
|------|----------------|
| 생성 안 됨/에러 | `Ctrl+L` 로그 열기 → 빨간 글자 확인 → ComfyUI 콘솔 확인 |
| 모델 안 뜸 | `⚙️ 설정` → 모델 폴더 경로 재확인 → `연결 확인` |
| 프롬프트 이상함 | `Ctrl+Shift+Enter` 마법사 재실행 → 영문 프롬프트 직접 수정 |
| 얼굴 망함 | FaceDetailer ON → Denoise 0.3 → 재생성 |
| 너무 느림 | 해상도 512×512 → Steps 15 → FaceDetailer OFF → 테스트 후 단계적 올리기 |
| VRAM 부족 | GGUF 모델로 변경 → 해상도↓ → FaceDetailer OFF |
