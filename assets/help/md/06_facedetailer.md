# FaceDetailer 얼굴 보정

이미지 생성 후 **얼굴이 뭉개지거나 이상하게 나온 경우**, 얼굴 영역만 자동으로 찾아서 한 번 더 정교하게 다시 그려주는 기능입니다.

## 이 기능은 뭔가요?

- 생성된 이미지에서 **얼굴을 자동 감지** (YOLO + SAM)
- 감지된 얼굴 영역을 **마스크로 분리**
- 해당 영역만 **Denoise 강도로 다시 생성** (인페인팅 방식)
- 주변과 자연스럽게 블렌딩 (Feather 처리)

**켜기(체크)만 해도 기본값으로 충분히 좋은 결과가 나옵니다.** 어려우면 값은 그대로 두세요.

---

## 초보자 추천 3단계

| 단계 | 설정 | 설명 |
|------|------|------|
| **1단계** | 체크박스 **OFF** | 기본 생성만, 얼굴 보정 안 함 (가장 빠름) |
| **2단계** | 체크박스 **ON**, 모든 값 **기본값 유지** | 보통 이 정도면 충분함 (추천) |
| **3단계** | 문제 시 미세 조정 | 아래 "자주 생기는 문제" 참조 |

---

## 17개 옵션 상세 설명

### 기본 그룹 (가장 많이 조정)

| 옵션 | 의미 | 기본값 | 조정 가이드 |
|------|------|--------|-------------|
| **Denoise** (얼굴 다시그리기 정도) | 얼굴을 얼마나 새로 그릴지. 높으면 완전히 바뀜 | 0.40 | 얼굴이 너무 변하면 **0.25~0.30**으로 낮춤 |
| **Steps** (보정 정밀도) | 고치는 계산 횟수. 높을수록 정교하지만 느림 | 20 | 15~25 사이 권장, 30 이상은 비추천 |
| **CFG** (프롬프트 반영 세기) | 긍정/부정 프롬프트를 얼마나 반영할지 | 4.0 | 3~5 사이, 너무 높으면 부자연스러움 |
| **Feather** (얼굴 경계 자연스럽게) | 고친 얼굴과 주변을 부드럽게 이어줌 | 5 | 3~10, 피부톤 차이 날 때 올림 |
| **Drop Size** (작은 얼굴 무시) | 이보다 작은 얼굴(픽셀)은 보정 안 함 | 10 | 단체 사진 시 작게 나온 얼굴 제외용 |

### 분석/크기 그룹

| 옵션 | 의미 | 기본값 | 조정 가이드 |
|------|------|--------|-------------|
| **Guide Size** (얼굴 분석 크기) | 얼굴을 분석하는 해상도. 클수록 정밀 | 256 | 256~512, 작으면 빠름/대략적, 크면 느림/정밀 |
| **Max Size** (보정 최대 크기) | 한 번에 보정하는 최대 픽셀 크기 | 768 | 512~1024, 큰 얼굴 잘리면 올림 |
| **Cycle** (보정 반복 횟수) | 몇 번 반복해서 보정할지 | 1 | 1~2, 보통 1로 충분 |

### 얼굴 감지 그룹 (YOLO BBox)

| 옵션 | 의미 | 기본값 | 조정 가이드 |
|------|------|--------|-------------|
| **BBox Thresh** (얼굴 찾기 민감도) | 얼굴을 얼마나 민감하게 찾을지 | 0.50 | **얼굴 못 찾을 때 0.40~0.45로 낮춤** |
| **BBox Dilate** (얼굴 박스 넓히기) | 잡은 얼굴 주변 박스를 넓힘 | 10 | 5~20, 머리카락/귀 잘리면 올림 |
| **Crop Factor** (얼굴 주변 같이 보기) | 얼굴 주변을 얼마나 함께 볼지 | 1.50 | 1.2~2.0, 맥락 포함 위해 조정 |

### SAM 마스크 그룹 (정밀 마스크용)

> **참고**: ComfyUI에 SAM 모델(`sam_vit_b_01ec64.pth`)이 설치되어 있어야 완전히 동작합니다. 미설치 시 YOLO 박스 기준으로 동작하며, 외형상 오류는 없습니다.

| 옵션 | 의미 | 기본값 | 비고 |
|------|------|--------|------|
| **SAM Thresh** (윤곽선 정밀도) | 얼굴 윤곽선(마스크)을 얼마나 정밀하게 | 0.93 | 높으면 정교, 낮으면 넉넉 |
| **SAM Dilate** (윤곽선 넓히기) | 윤곽선(마스크)을 픽셀 단위로 넓힘 | 0 | 보통 0~5 |
| **SAM BBox Exp** (윤곽선 영역 넓히기) | 윤곽선 작업 영역을 박스 기준으로 넓힘 | 0 | 보통 0~10 |
| **Mask Hint Thresh** (힌트 민감도) | 마스크 힌트 적용 판정 민감도 | 0.70 | SAM Hint 사용 시 조정 |

### SAM Hint (얼굴 위치 힌트) - 9가지 모드

| 모드 | 설명 | 추천 상황 |
|------|------|-----------|
| **center-1** | 가운데 1점 | **기본, 가장 안전, 단일 얼굴** |
| horizontal-2 | 가로 2점 | 좌우 두 얼굴 |
| vertical-2 | 세로 2점 | 상하 두 얼굴 |
| rect-4 | 사각 4점 | 여러 얼굴 그리드 |
| diamond-4 | 마름모 4점 | 대각선 구도 |
| mask-area | 마스크 영역 기준 | 고급, 기존 마스크 활용 |
| mask-points | 마스크 포인트 기준 | 고급 |
| mask-point-bbox | 마스크 포인트+박스 | 고급 |
| **none** | 힌트 사용 안 함 | SAM 미사용 시 |

## 필수 사전 설치 (ComfyUI Manager에서)

FaceDetailer가 제대로 동작하려면 ComfyUI에 다음 3가지가 **반드시 설치**되어 있어야 합니다.

### 1. Impact Pack (보정 필수 뼈대)
```
ComfyUI Manager → Install Custom Nodes
검색: "Impact Pack"
설치: ComfyUI-Impact-Pack (작성자: ltdrdata)
→ ComfyUI 서버 완전 재시작 필수!
```

### 2. SAM 모델 (정밀 마스크용)
```
ComfyUI Manager → Install Models
검색: "sam_vit_b"
설치: sam_vit_b_01ec64.pth
→ 저장 위치: ComfyUI/models/sams/
```

### 3. YOLO 모델 (안면 감지용)
```
ComfyUI Manager → Install Models
검색: "face_yolov8m"
설치: bbox/face_yolov8m.pt
→ 저장 위치: ComfyUI/models/ultralytics/bbox/
```

## 자주 생기는 문제

| 문제 | 원인 | 해결 |
|------|------|------|
| **얼굴을 못 찾아요** | BBox Thresh 너무 높음 | **0.40~0.45로 낮추기** (가장 흔한 해결) |
| **보정된 얼굴이 다른 사람 같아요** | Denoise 너무 높음 | **Denoise 0.25~0.30으로 낮추기**, CFG 3~4로 |
| **얼굴 경계가 티나요** | Feather 부족 | **Feather 8~15로 올리기** |
| **머리카락/귀가 잘려요** | BBox Dilate 부족 | **BBox Dilate 15~25로 올리기** |
| **너무 느려요** | Steps 높음 / 큰 해상도 | **Steps 15~20으로**, FaceDetailer 필요한 이미지에만 ON |
| **여러 얼굴인데 하나만 보정** | SAM Hint 모드 부적절 | **horizontal-2 / rect-4 등으로 변경** |
| **SAM 옵션이 안 먹혀요** | SAM 모델 미설치 | 위 "필수 사전 설치"에서 SAM 모델 설치 |

---

## 성능 팁

1. **필요한 이미지에만 켜기**: 매번 켜지 말고 얼굴 중요할 때만
2. **Steps 20 이하 유지**: 30 이상은 속도 대비 효과 미미
3. **해상도 고려**: 1024×1024 기준 2~5초 추가 소요
4. **단체 사진**: `horizontal-2` 또는 `rect-4` 힌트 모드 사용

## 워크플로우 내 동작 원리 (참고)

```
생성 완료 이미지
    │
    ▼
YOLO 얼굴 감지 (bbox/face_yolov8m.pt)
    │
    ▼
BBox Thresh로 신뢰도 필터링
    │
    ▼
SAM 정밀 마스크 (sam_vit_b_01ec64.pth, 설치 시)
    │  (미설치 시 YOLO 박스 그대로 사용)
    ▼
마스크 영역 추출 + Feather 블러
    │
    ▼
인페인팅 재생성 (Denoise, Steps, CFG 적용)
    │
    ▼
원본 이미지에 블렌딩
    │
    ▼
최종 결과
```
