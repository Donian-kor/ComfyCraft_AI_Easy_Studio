❓ 얼굴 보정(FaceDetailer) 쉬운 설명서

🎯 이 기능은 뭔가요?

이미지를 만든 뒤 얼굴이 뭉개지거나 지저분하면, 얼굴만 자동으로 찾아서 한 번 더 고쳐주는 기능입니다. 켜기(체크)만 해도 기본값으로 충분히 좋은 결과가 나옵니다. 어려우면 값은 그대로 두세요.

🚶 초보자 추천 3단계

  • 1단계: 체크박스를 끈 채 그대로 사용합니다. (기본)
  • 2단계: 체크박스를 켜고 모든 값은 그대로 둡니다. 보통 이 정도면 충분합니다.
  • 3단계: 얼굴을 못 찾으면 얼굴 찾기 민감도(BBox Thresh)를 0.40~0.45로,
        얼굴이 너무 변하면 얼굴 다시그리기 정도(Denoise)를 0.25~0.30으로 낮춰 봅니다.

📍 SAM Hint(얼굴 위치 힌트) 9가지란?

  • center-1 : 가운데 1점. 기본이고 가장 안전함
  • horizontal-2 / vertical-2 : 가로/세로 2점
  • rect-4 / diamond-4 : 사각/마름모 4점
  • mask-area / mask-points / mask-point-bbox : 마스크 기준(고급)
  • none : 힌트 사용 안 함

⚠️ 참고: SAM 옵션이 전부는 아닌 이유

현재 ComfyUI에 SAM 모델이 연결되어 있지 않아서, SAM 계열 옵션(SAM Thresh/Dilate/BBox Exp, SAM Hint 등)은 일부만 반영되고 YOLO 얼굴 박스 기준으로 주로 동작합니다. 외형상 오류는 없으며, 안전 기본값 그대로 사용하시면 됩니다.

🛠️ 자주 생기는 문제

  • 얼굴을 못 찾아요: BBox Thresh를 0.4~0.45로 낮춰 보세요.
  • 보정된 얼굴이 다른 사람 같아요: Denoise를 0.25~0.3, CFG를 3~4로 낮춰 보세요.
  • 너무 느려요: Steps를 20 이하로, FaceDetailer를 필요한 이미지에만 켜세요.
